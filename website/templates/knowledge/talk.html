{% elif slide.visual == 'workflow' %}
“Add the denver.space logo to the PCB silkscreen.”
  1. Set the constraintsUse the official artwork. Keep copper, components and the board outline unchanged.
  2. Investigate and implementAI reads the existing design and writes a script to generate native KiCad artwork.
  3. Inspect and correctI review the rendered board, give feedback on placement and legibility, and ask for another pass.
  4. Check and keep the toolCompare the electrical design, run the board checks and save the generator for the next revision.

One request leaves behind a reusable silkscreen generator. The same workflow applies to PCB edits, case dimensions and firmware—with physical tests for fit and behavior.
