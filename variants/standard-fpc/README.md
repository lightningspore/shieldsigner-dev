# Historical 40-pin FPC carrier

This is the preserved former top-level KiCad design. The current eight-pin,
four-layer carrier is in [`../../kicad/`](../../kicad/). Do not mix manufacturing
files between these designs. The historical DNP strap exceptions remain in
`docs/drc-assembly-exceptions.json`.

Run `mise run kicad:standard:check` to validate this historical design.
