# Eight-pin pill KiCad project — 0.0.4-dev

Open `SeedSigner-Plus-smartcard-pico.kicad_pro` with KiCad 10, or run `mise run variant:lcd:open` from the repository root. This independent variant keeps the upstream basename for hierarchical annotation paths.

Use the [pill design/pinout](../../../docs/LCD-MODULE-VARIANT.md), [customer assembly guide](../../../docs/MODULAR-ASSEMBLY.md) and [matching prototype quote files](../manufacturing/README.md). It is a 160×70 mm capsule with a single eight-pin SPI LCD socket, independent 3.3 V LCD supply and the smartcard reader. It has no FPC connector, Pico-format LCD footprint or DNP strap exceptions.

The original [upstream assembly README](UPSTREAM-README.md) is retained for provenance; its panel, jumpers, mounting and parts instructions are not the build instructions for this pill carrier. MIT/upstream attribution is retained in the repository and native changelog.
