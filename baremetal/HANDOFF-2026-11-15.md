**Follow-up static audit (same class as `log2`):** frozen `ur2/fountain_decoder.py` called `time.time()` in `process_queue_item`, but the baremetal `time` module (`micropython/modmachine.c`) exports only `ticks_ms` and `sleep_ms`. Every multipart UR part would raise `AttributeError` on device, while host CPython masked it. The value only fed a commented-out debug print, so `tools/prepare_ur.py` now removes that line and records the change in `app/ur-provenance.json`; the fountain algorithm is unchanged. No wall clock was added (uptime must not stand in for wall time). `tests/test_native_time_attributes.py` checks every frozen manifest module against the native `time` export table and fails on the original source. The other builtin-module uses (`math.ceil/floor/ldexp/log2`, `re` via PCRE2 `re.py`/`qr_regex.py`) resolve on the current config. 150 host tests pass. Overlap check: `firmware/lvgl-app` is the separate Linux/LVGL frontend that runs CPython-compatible Python; baremetal already sources its pinned app snapshot (`dist/firmware/sources/lvgl/application`, `firmware/lvgl-app/sources.lock.json`) instead of duplicating it, and that Linux runtime cannot hit these MicroPython-only missing attributes.

Both images are 3,145,728 bytes (3 MiB), profile `app`, feature `app-autostart`, USB identity `rv1103-dut1`. The ELF now contains `log2`, `mp_math_log2`, and `mp_math_log2_obj`. The entropy algorithm is unchanged. ## Bench and operating constraints

DUT1 is the RV1103 Mini A with no NAND and the LCD/button PCB plus SC3336 camera, USB serial `rv1103-dut1` (normally `/dev/cu.usbmodemrv1103_dut11`). With SD installed, USB reset boots the card rather than entering maskrom. Do not interrupt or reset it while the user is operating the UI.

DUT0 is a separate RV1103 Mini A with a loopback jumper installed. Do not load `app-ui`, `mini-pcb-ui` or `usb-only` onto DUT0. REF is a Luckfox Pico, not a Mini; preserve its Linux installation. REF/ADB was unavailable at handoff. No current device connection state is implied by these descriptions.

LCD pins: CS48, SCK49, MOSI50, reset51, DC52, backlight43. Buttons: Up57, Down59, Left56, Right54, center58, KEY1 55, KEY2 global4, KEY3 53. Use the documented Mini PCB profile rather than older fixture wiring.

Never allocate in IRQ context or let MicroPython NLR cross C++/Rust frames. Keep borrowed camera-buffer ownership explicit. Do not save private camera frames, entropy, mnemonic words or wallet data into receipts or logs.

## Session update: hands-free DUT1 verification (2026-11-15, later)

DUT1 (maskrom LocationID 101) was RAM-loaded with `mise run baremetal:ui:dut1:build` and `tools/usb_only_gate.py`; no SD or storage writes. All results below are RAM-only development images, not a flashed card.

**Hands-free recovery.** USB console input is polled, so a wedged native call previously required a manual power cycle. `src/watchdog.rs` now enables the RV1106 DesignWare watchdog (`0xff5a0000`, tclk 24 MHz, ~44.7 s) on usb-only builds, fed from the VM hook and `usb::poll`. `machine.watchdog_status()` reads CR/TORR/CCVR/gate; `machine.watchdog_selftest()` performs an IRQ-disabled stall. Self-test returned DUT1 to maskrom in ~37 s without hands; a later real wedge also recovered by itself. Native interruptible PBKDF2 feeds through `usb::poll`, so it is not a stall test.
